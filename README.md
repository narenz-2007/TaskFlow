# TaskFlow - Offline-First Task Organizer

A modern, offline-first daily task organizer built with Jetpack Compose & Material 3 Design.

## ✨ Features
- 📱 100% Offline - No internet needed
- 🎨 Jetpack Compose & Material 3
- 🔥 Productivity Streak Tracker
- 📊 Habit Analytics & Insights
- 🌙 Dark/Light Mode
- ⚡ Fast & Lightweight

## 🛠️ Tech Stack
- Kotlin
- Jetpack Compose
- Room Database
- MVVM Architecture
- Material 3

## 🚀 Installation
1. Clone the repo
2. Open in Android Studio
3. Build & Run
